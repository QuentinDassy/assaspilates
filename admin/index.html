Plugin WordPress

Le module de réservation est géré par le plugin booking-manager (dans le dossier /plugin de ce projet). Pour l'installer :

  1. Zippez le dossier plugin/
  2. WordPress → Extensions → Ajouter → Téléverser
  3. Activez le plugin
  4. Allez dans Réservations → Paramètres et entrez vos clés Stripe
  5. Ajoutez [booking_courses] sur la page de réservation
